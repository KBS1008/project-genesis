# Purpose

This document defines every major screen of Project Genesis before
production-quality artwork is created.

Each screen specification contains:

- Purpose
- Information hierarchy
- Layout
- Required UI components
- Required charts
- Required maps
- Required icons
- User interactions
- Planned mockup status

This document becomes the blueprint for all future generated mockups.

# Mockup Status

|----------|----------|
| Planned | Specification only |
| Wireframe | Layout approved |
| Mockup | High-fidelity design created |
